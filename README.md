# Rewrite KDE Plasma Widgets

KDE Plasma 6 ports of the Windows 7 desktop gadgets from Rewrite: Harvest festa! by Key/VisualArt's.

![Preview](/preview.png)

## Widgets
- **AkaneWatch** - clock widget with Akane Senri
- **ChihayaWatch** - clock widget with Chihaya Ohtori
- **KagariWatch** - clock widget with Kagari
- **KotoriWatch** - clock widget with Kotori Kanbe
- **LuciaWatch** - clock widget with Lucia Konohana
- **SizuruWatch** - clock widget with Sizuru Nakatsu
- **ChihayaCPU** - CPU monitor widget with Chihaya
- **KagariCannon** - clicker widget with Kagari

## Install

From KDE Store: https://store.kde.org/u/fuckingshit141/products

Or manually:
```bash
kpackagetool6 --type Plasma/Applet --install org_kde_akanewatch.plasmoid
kpackagetool6 --type Plasma/Applet --install org_kde_chihayawatch.plasmoid
kpackagetool6 --type Plasma/Applet --install org_kde_kagariwatch.plasmoid
kpackagetool6 --type Plasma/Applet --install org_kde_kotoriwatch.plasmoid
kpackagetool6 --type Plasma/Applet --install org_kde_luciawatch.plasmoid
kpackagetool6 --type Plasma/Applet --install org_kde_sizuruwatch.plasmoid
kpackagetool6 --type Plasma/Applet --install org_kde_chihayacpu.plasmoid
kpackagetool6 --type Plasma/Applet --install org_kde_kagaricannon.plasmoid
```
